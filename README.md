# 漾澤 drshinehair｜年度營運儀表板 V01

沿用愛美肌定稿四頁架構，獨立淺藍版。資料期間由私人來源決定，2026年度為2025/12至2026/11。

## 安全架構

- 公開儲存庫只有程式，不含PDF、營運數字、存取權杖或密碼。
- Google登入使用Sheets唯讀授權；實際存取由來源Sheet共用權限決定。
- Google OAuth Client ID不是密碼。不得加入Client Secret。
- 共用既有已授權的GitHub Pages來源登入設定，不修改愛美肌程式或資料。
- 資料只存在登入後記憶體；登出、逾時、讀取失敗清除資料。不使用持久化儲存。

## 結構與更新

- `dashboard.template.html`：固定淺藍四頁版型。
- `dashboard-data.js`：月份、三店、新舊客、資料完整性與加總驗證。
- `dashboard.js`：Google登入、即時讀取、篩選、每5分鐘可見頁面更新。
- `config.js`：私人Sheet識別碼與公開OAuth client ID。
- `node build_v02.js`：檢查語法並產生index.html。
- `node --test dashboard.test.js`：合成測試資料，不含真實營運數字。

## 計算規則

- 新客實績為依預約日期的新客消費數，不是到店數或客服詢問數。
- 桃園、江翠、三峽同月份完整匯入才顯示；不跨月去重。
- 新客目標未知為空白；任一所选項目缺目標，不顯示達成率與落後數。
- 消費金額、消費數、到店數按月份／客群與月報總覽核對。
- 平均客單＝金額÷到店數，累積以總額總数重算；中位數不加總。
- Meta僅用平台詢問數，CPA＝已配對訊息花費÷平台詢問數。
- Meta 整體包含「品牌整體」活動；單店篩選只計入活動名稱可明確對應桃園、江翠或三峽的資料，不把無分店名稱的活動硬分攤。
- 未知廣告花費及預算不當成0，缺資料明確標示。
- Meta與年度預算的同月花費不一致會停止顯示。
- 本機file來源不支援Google登入；正式版使用已授權的HTTPS來源。

私人驗收、月報、日誌、帳號清單與數值匯出皆保存在本機／AI工作中樞，不加入Git。
